# Rótulos de triagem

As skills falam em cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para os textos de rótulo realmente usados no rastreador de Issues deste repositório.

| Rótulo em mattpocock/skills | Rótulo no nosso rastreador | Significado                                         |
| --------------------------- | -------------------------- | --------------------------------------------------- |
| `needs-triage`              | `needs-triage`             | Quem mantém o projeto precisa avaliar esta Issue    |
| `needs-info`                | `needs-info`               | Aguardando mais informações de quem relatou         |
| `ready-for-agent`           | `ready-for-agent`          | Totalmente especificada, pronta para um agente AFK  |
| `ready-for-human`           | `ready-for-human`          | Exige implementação por uma pessoa                  |
| `wontfix`                   | `wontfix`                  | Não será tratada                                    |

Quando uma skill mencionar um papel (por exemplo, "aplique o rótulo de triagem pronto para AFK"), use o texto correspondente desta tabela.

Edite a coluna "Rótulo no nosso rastreador" para acompanhar o vocabulário que você realmente usar.
