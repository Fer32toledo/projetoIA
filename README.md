# projetoIA

Projeto do curso na área da saúde. Este repositório ainda está em fase inicial: por enquanto
guarda apenas a documentação de apoio ao trabalho e as convenções combinadas para o projeto.

## Estrutura atual

- `AGENTS.md`: regras de trabalho do projeto (privacidade, uso de dados fictícios, fluxo de Git e verificação).
- `README.md`: este arquivo.
- `docs/agents/`: configuração das skills de engenharia (onde ficam as Issues, rótulos de triagem e documentação de domínio).

## Como rodar testes e verificações

Ainda não há código, testes nem integração contínua (CI) configurados. Quando existirem, os comandos
de teste e de análise estática serão registrados aqui.

## Privacidade

Use somente dados fictícios ou anonimizados. Nunca coloque dados de pacientes, de estudantes ou de
participantes de pesquisa neste repositório, em Issues ou em modelos de IA. Não versione chaves,
senhas, tokens ou arquivos `.env` com segredos.
